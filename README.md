## Source code & download

This repository is public. The site is a static build: `index.html` + `Asset/dist/app.js` + `Asset/dist/app.css`, with the React + Framer Motion source in `src/`.

```bash
git clone https://github.com/Abrar9666/Abrarhashmi-pro.git
cd Abrarhashmi-pro
```

To rebuild from source (in the original project folder):

```bash
npm run build
```

The build output is `index.html` + `Asset/dist/app.js` + `Asset/dist/app.css`. Deploy the three files together to any static host — this repo's live copy is deployed on Vercel.
